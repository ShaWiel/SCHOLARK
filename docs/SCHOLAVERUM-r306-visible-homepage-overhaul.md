# SCHOLAVERUM r306 — Visible Homepage Redesign

## Why
The prior r305 release changed feature canvases predominantly below the fold. Users entering the homepage reasonably saw essentially the old hero. This release replaces the visible first-screen composition and the overall page hierarchy rather than another minor cinematic polish.

## Visible changes
- Above the fold: substantially different typographic composition, violet depth, improved brand-colour treatment, retained official approved logo/planet, and a first-screen interactive feature dock with real ARKI / AI Tutor / Languages / Schools routes.
- Intro: two-column editorial composition with a distinctive orbital learning journey illustration.
- Product theater: redesigned active feature navigation and immersive preview display.
- Two feature panels: deeper hover-independent graphical compositions for languages and worldwide school discovery.
- Toolkit: graphic 3×2 product tiles instead of the old rule-divided icon list.
- Final CTA: violet cosmic spatial atmosphere with concise orbital indicators.
- Mobile: visible 2-column feature dock, stacked intro composition, single-column toolkit; reduced-motion and accessibility support.
- Official planet, branding, pricing functionality, translation ownership and service interactions retained.

## Gates
- r306 browser regression asserts the new first-screen dock is present and has working feature routing, the redesigned sections are rendered, the official hero logo and billing cards remain, and mobile has no horizontal overflow.
- Existing r299–r305 and Workspace/browser regression suites remain mandatory.
- No Supabase schema, Edge Functions or secrets changed. Paddle sandbox remains untouched.
