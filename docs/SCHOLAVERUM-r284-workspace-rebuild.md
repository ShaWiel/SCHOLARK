# SCHOLAVERUM r284 — Workspace rebuild and surface ownership

The Workspace now starts with a calm, serif-led dashboard, an assistant composer, study starters, recent tools, next actions, a collapsible education-level picker and a compact tool directory. ARKI and AI Tutor use the same warm reading surfaces and serif headings; their conversations lead the page and connected insights follow below. The canonical dashboard is produced by V51 from one template and retains the existing study tools, stored work and Coming Soon boundaries.

The recurring double-surface defect had several contributors: old foundation CSS made the Workspace transparent; the old Tutor helper removed a canonical dashboard card; independent decorators inserted legacy dashboard panels; and the old homepage adapter could mistake Credit Store for retired homepage content. These owners now respect the canonical surfaces. Pricing is mounted independently of the retired homepage shell.

The head-level boot guard hides retired homepage content before body parsing and waits for the editorial homepage and its stylesheet before revealing it. Failure keeps a branded reload screen instead of revealing the legacy page. The runtime manifest and service worker always revalidate, module release URLs are advanced, and the changed foundation script has a fresh URL.

The guided presentation uses cancellable fade, depth and camera transitions. Closing, leaving the page, changing motion preference and manual scrolling clean up in-flight animations and timers. Reduced-motion navigation remains immediate.

Programmatic tool entry now loads its lazy dependencies, and composer handoffs wait for the target feature. Saved-data access tolerates malformed records, preserves text-only legacy tasks and goals, assigns stable non-colliding recovery IDs and excludes undated completions from weekly completion counts. Canonical interface copy is included for the seven built-in language dictionaries; adaptive language support remains with the existing engine.

Validation includes the r284 cold-start/frame visibility, cache, assistant handoff, translations, structural repair, mobile, Pricing/Credit Store and cinematic cancellation browser regression; the saved-data integrity contract; retained r282/r283, security/session/account-isolation and release checks. Production deployment remains blocked until the release gate passes, followed by live verification.
